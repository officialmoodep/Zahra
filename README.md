# سایت زهرا 💙🖤❤️

یک سایت کامل و جدا-جدا (HTML / CSS / JS) با Bootstrap و jQuery برای داستان عشق شما، با تم آبی-مشکی-قرمز. عکس، فیلم و موزیک همه به‌صورت لینک هستن — فایلی روی سرور لازم نیست.

## ساختار فایل‌ها
```
baraneh-site/
├── index.html          → همه‌ی بخش‌های سایت (فقط ساختار، بدون لینک هاردکد)
├── css/style.css        → تمام استایل‌ها، رنگ‌ها، انیمیشن‌ها، افکت سه‌بعدی
├── js/config.js          → 📌 تنها فایلی که باید ویرایش کنید (اسم، تاریخ، لینک‌ها)
└── js/main.js            → منطق سایت (تایمر، گالری، موزیک) — نیازی به دست‌زدن نیست
```

## چطور شخصی‌سازی کنید (همه‌چیز داخل `js/config.js` است)

1. **اسم پارتنر:**
   ```js
   partnerName: "زهرا",
   ```

2. **تاریخ شروع رابطه (شمسی):**
   ```js
   startJalali: { y: 1405, m: 7, d: 18, hour: 23, minute: 45 }, // ۱۸ مهر ۱۴۰۵ ساعت ۲۳:۴۵ (به وقت ایران)
   ```
   خودِ کد این تاریخ را با یک الگوریتم استاندارد به میلادی تبدیل می‌کند (۱۸ ژوئیه‌ی ۲۰۲۶)، پس کافیست فقط همین سه عدد را عوض کنید.

3. **موزیک پس‌زمینه:** یک لینک مستقیم mp3 (مثلاً از هاست فایل شخصی، Google Drive با لینک مستقیم، یا هر سرویس دیگر) جای لینک نمونه بگذارید:
   ```js
   music: { url: "لینک-mp3-شما", title: "اسم آهنگ" }
   ```
   دکمه‌ی دیسک‌گرامافون گوشه‌ی پایین-چپ سایت پخش/توقف را کنترل می‌کند. مرورگرها معمولاً پخش خودکار با صدا را مسدود می‌کنند، برای همین با اولین کلیک کاربر روی صفحه یا خودِ دکمه، پخش شروع می‌شود.

4. **عکس‌های مکعب سه‌بعدی «کهکشان عشق»:** دقیقاً ۶ لینک در `cubePhotos`.

5. **گالری عکس:** هر تعداد لینک در `galleryPhotos`.

6. **گالری فیلم:** هر آیتم یک `poster` (عکس کاور) و یک `src` (لینک مستقیم ویدیو) در `videos`.

7. **متن نامه و خاطرات:** در `index.html` بخش‌های `#letter` و `#timeline` را با متن واقعی خودتون عوض کنید — جاهایی که با ✏️ علامت‌گذاری شده‌اند.

8. **رنگ‌ها:** بالای فایل `css/style.css` در بخش `:root` (`--blue`, `--red`, `--bg-deep` و...).

## جزئیات خاص این نسخه
- تایمر با افکت فلیپ سه‌بعدی، شمارش زنده‌ی سال/ماه/روز/ساعت/دقیقه/ثانیه که هرگز متوقف نمی‌شود
- مکعب سه‌بعدی چرخان («کهکشان عشق») + یک قلب سه‌بعدی چرخان در هیرو
- پخش‌کننده موزیک شناور با دیسک گرامافون که هنگام پخش می‌چرخد
- کاملاً واکنش‌گرا برای موبایل، قلب‌های شناور در پس‌زمینه، ستاره‌های چشمک‌زن

## اجرا
فقط فایل `index.html` را در مرورگر باز کنید (یا کل پوشه را روی هاست/گیت‌هاب‌پیجز آپلود کنید). به اینترنت نیاز دارد چون فونت‌ها، آیکون‌ها، Bootstrap، jQuery و لینک‌های عکس/فیلم/موزیک از بیرون لود می‌شوند.
